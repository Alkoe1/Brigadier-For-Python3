# Brigadier-For-Python3
This is a Python 3 port of the original brigadier tool by timsutton. Since the original project is no longer maintained for modern Python versions, this fork provides compatibility for Python 3. Its not an official version. Its just modified and converted to modern Python 3.

# How to use it?

If you don't have the Broadcom drivers to use internet on windows, first you should use the program in your terminal in MacOS. To do that:

cd (brigadier folder) 

python3 brigadier

Then brigadier will do it's job. 

After these you should extract the files installed by brigadier into a USB flash drive. After that, restart and log into windows. Install the necessary things from the USB. 

For more information and more parameters, take a look to the usage of official version.
